    How to run a squad

    Keep it small. Two to four people is enough. Pick friends who will actually check in.

    Same weekly target. For example, five practice problems each (50 XP). The weekly board resets every Monday, so a late joiner is never far behind.

    Swap codes every Sunday. Send your invite link in your group chat and open theirs. Takes about a minute.

    This site has no server, so a friend’s numbers only change when they send you a fresh code. Codes can be edited by whoever holds them, so treat the board as friendly competition, not a ranking you can trust to the last point.
